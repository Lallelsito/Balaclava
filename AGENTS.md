# Reglas del proyecto Balaclava

## Regla de seguridad de Git
- Antes de modificar cualquier archivo, asegúrate de que el estado actual esté limpio en Git (`git status`).
- Una vez que termines la tarea y verifiques que el juego funciona, ejecuta:
  1. `git add .`
  2. `git commit -m "Backup: [nombre de la tarea]"`
  3. `git push` a GitHub (`origin main`)
